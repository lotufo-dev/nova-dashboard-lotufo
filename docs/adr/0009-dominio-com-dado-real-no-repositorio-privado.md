# Conhecimento de domínio com dado real mora no repositório privado

Este repositório é público, e boa parte do que se sabe do domínio leva nome de obra, de órgão, centro de custo ou
consulta do RM. Esse conhecimento vivia na memória do assistente, uma pasta sem versão numa máquina só. Decidimos
separar em três lugares: o termo genérico fica no `GLOSSARY.md` daqui; o fato com nome real fica no repositório
privado do cadastro, que tem histórico e já guarda as análises; a memória fica com as preferências do dono e os
ponteiros.
